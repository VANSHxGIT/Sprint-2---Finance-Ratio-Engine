# Finance Ratio Engine (Sprint 2)

A Python project for calculating and analyzing financial ratios. 

## Setup

1. Create a virtual environment: `python -m venv .venv`
2. Activate the virtual environment:
   - Windows: `.venv\Scripts\activate`
   - Linux/Mac: `source .venv/bin/activate`
3. Install dependencies: `pip install -r requirements.txt`

## Structure
- `src/`: Core analytics and calculation engine.
- `tests/`: Unit tests (run with `pytest`).
- `data/` and `database/`: Data sources and SQLite databases.
- `outputs/`: Generated analysis and log files.

## Usage
Run the engine via `run_ratio_engine.py`:
```bash
python run_ratio_engine.py
```
